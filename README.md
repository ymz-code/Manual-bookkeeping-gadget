# 极简记账本
一款清爽干净的本地记账工具，主打轻量无广告，所有账本数据保存在本地，保护你的收支隐私，轻松管理日常开销、资产与负债。

## ✨ 功能特性
- **快速记账**：支持支出 / 收入 / 转账，内置餐饮、交通、购物、居家、医疗、娱乐、学习、旅行等常用分类，可添加备注
- **收支明细**：按时间线展示全部账单，直观查看每一笔消费
- **预算管控**：设置月度预算，实时查看预算占用比例，帮你控制花销
- **统计图表**：环形饼图展示各类支出占比，近七日柱状图查看消费趋势
- **资产台账**：管理储蓄卡、支付宝、微信零钱、现金等资金账户；同时记录花呗、白条等负债，自动计算总资产、总负债与净资产
- **个人设置**：自定义收支分类、账户管理、记账提醒、本地数据备份
- **打卡激励**：记录记账天数、连续打卡、累计结余，养成记账习惯

## 📖 使用说明
1. **开始记账**
   点击底部红色加号，选择支出 / 收入 / 转账，填写金额、分类、账户与备注，保存入账。
2. **查看账单**
   在「明细」页浏览全部流水；切换至「图表」查看月度消费分布与近七天支出。
3. **管理资产负债**
   在「资产」页面添加银行卡、零钱等资产账户，录入信用负债，自动核算净资产。
4. **个性化配置**
   进入「我的」页面，自定义收支分类、开启记账提醒、导出本地备份。

## 📌 数据说明
- 所有账本数据默认保存在本地，不上传云端；
- 建议定期使用数据备份功能，防止误删丢失账单；
- 当前版本：v1.1

## ⚠️ 注意事项
- 转账用于不同账户之间资金流动，不计入收入与支出；
- 预算仅做消费参考，不会限制记账操作。
